# Reflection – Week 2

**Name: Pranathi**

Week 2 of the DevOps Micro Internship (DMI) Cohort 3 with Agentic AI was a very interesting learning experience for me. During this week, I learned how AI tools can be used not only for answering questions but also for helping with development and DevOps tasks.

One of the main topics I learned was Claude Code. I understood that Claude Code can work with a project and help developers perform different tasks using natural language. At first, I found some of the commands and workflows confusing, but after practicing step by step, I became more comfortable using it.

I also learned about MCP (Model Context Protocol). MCP helps AI assistants connect with external tools and services. Working with GitHub MCP helped me understand how an AI assistant can access information from a repository and work with external systems.

Another important topic I learned was Hooks and Permissions. Hooks can be used to control or monitor actions performed by an AI agent. I worked with safety hooks that could detect potentially dangerous commands such as terraform destroy or destructive file operations. This helped me understand why safety controls are important when using AI agents for DevOps activities.

I also explored Memory in Claude Code. I learned that project memory can store important information and help the AI remember it across sessions. This was especially interesting because it showed me how persistent memory can make an AI assistant more useful for long-term projects.

During this week, I faced some challenges, especially when commands did not work as expected and when I received errors from the tools. Instead of giving up, I learned to troubleshoot the problem, understand the error, and try again. This improved my confidence and patience while working with new technologies.

One habit I plan to implement is to document important commands, errors, and solutions while working on every project. This will help me troubleshoot problems faster and avoid repeating the same mistakes.

Overall, Week 2 helped me understand Agentic AI, Claude Code, MCP, Hooks, Permissions, and Memory in a practical way. I learned that using AI effectively requires not only technical knowledge but also patience, testing, and safe practices.
