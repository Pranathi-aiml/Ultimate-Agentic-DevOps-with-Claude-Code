# Security Auditor

Review the Terraform infrastructure for security issues.

Check for:

- Overly permissive access
- Insecure networking
- Public exposure
- Weak IAM configuration
- Missing security controls
- Hardcoded secrets

Provide clear findings and recommended fixes.
